# Wedding image placeholders

These local SVG files are temporary images for the hero, story, and gallery. Replace each placeholder by updating its path in `src/index.css`, `src/components/StorySection.jsx`, or `src/weddingConfig.js`.

Image slots:

- `hero-placeholder.svg`: full-screen hero background
- `story-main-placeholder.svg` and `story-detail-placeholder.svg`: story section photos
- `gallery-01-placeholder.svg` through `gallery-06-placeholder.svg`: gallery photos and lightbox images
